# Mochi Studio 0.6.0-beta.1

This community beta adds a personal room and more ways for Mochi to live on your desktop, on the official Coucou main revision `b1bc09de7f7c24a80bd8eca5729b8bee60f66402` (0.6 work).

- A separate resizable studio, four room styles, movable furniture, camera controls and adjustable lighting.
- Outfit combinations, saved looks and seven body appearances. Diamond Mochi keeps a rounded black body with many small bright stones.
- Automatic attachment to exposed window edges, arms, native window following and jumps, without Alt.
- Transparent PNG photos and independent desktop props.

Windows 10/11 x64: download and run the setup EXE, or choose the MSI. macOS 15+ Intel/Apple Silicon: open the universal DMG and drag Coucou into Applications. Close an existing Coucou process first. This beta uses Coucou's existing app identifiers and can replace an installation in the same location; back up your preferences before testing.

Both native builds must pass before a release is prepared. The release includes source/checksum manifests and actual Windows app QA and resource measurements. The Mac build checks both architectures and opens the packaged 3D studio in real WebKit, including PNG export. Test details and the remaining manual checks are in the presentation pack.

The default Windows build is unsigned. The default Mac build is ad-hoc signed and not notarized. Download and operating-system warnings may remain. Check each platform manifest for the actual signature status; a configured signing identity is not proof of a successful signature.
