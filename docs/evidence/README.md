# Browser evidence

Generated by `npm test` using headless Chromium with software WebGL on Linux.

- `viewport-WIDTH-PERCENT.png`: seven requested viewport sizes, captured at 0/20/40/60/80/100% scroll.
- `design-before.png`, `design-during.png`, `design-after.png`: the same pinned sequence at distinct scroll offsets.
- `motion-transforms.json`: measured CSS transform matrices, reverse-scroll comparison, project mask changes and About word-color changes.
- `cam-N-a.png`, `cam-N-b.png`: each of thirteen cameras sampled at two different times.
- `feed-motion.json`: SHA-256 of each temporal sample and the corresponding changed-pixel assertion.
- `library.png`: searchable library overview.
- `reduced-motion-mobile.png`: mobile page with reduced-motion preference enabled.
- `test-results.json`: Playwright's complete machine-readable report.

The temporal camera check proves pixel change; it does not quantify artistic quality or reference similarity. These are captures of the original local implementation. The reference website was inaccessible and has no comparison captures.
- `production-smoke.json`: five routes served from the built production bundle, including direct internal-route navigation, with HTTP statuses and console errors.
